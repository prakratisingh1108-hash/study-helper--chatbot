# 📚 Study Helper AI Chatbot

A simple chatbot for students to learn Maths, Science & English easily.

## Problem
Books use hard language and no teacher is available 24x7 for small doubts.

## Solution
This chatbot gives instant, short, simple answers. Just type a question or tap a topic button.

## Features
- Ask any question about Maths, Science, English
- One-click topic buttons
- Works on mobile, no login needed
- Fast and easy to use

## How to Use
1. Open `index.html`
2. Type your question or click a topic
3. Get instant answer

## Tech Used
HTML, CSS, JavaScript
